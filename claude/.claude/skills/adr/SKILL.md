# Architecture Decision Record

1. Inspect existing ADR conventions and relevant interfaces. Identify the decision,
   constraints, stakeholders and unresolved questions.
2. Compare viable options, including the status quo, with trade-offs and risks.
3. When a decision is authorized, create the next available numbered record under
   `docs/adr/` (or the project's existing ADR location). Include status, context,
   decision, alternatives, consequences and links to supporting evidence.
4. Do not present an unapproved proposal as an accepted decision or change
   application logic as part of this skill.
