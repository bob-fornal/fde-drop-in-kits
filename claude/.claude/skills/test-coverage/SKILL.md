# Coverage Gap Analysis

Identify changed files and run the project's existing coverage command if
available. Inspect uncovered branches and relevant callers, prioritizing failure
paths, boundaries and regressions over a numeric target. Add focused tests using
existing conventions and run them. Report the command, results, remaining gaps
and any missing coverage tooling; do not install tools without authorization or
claim coverage for unmeasured code.
