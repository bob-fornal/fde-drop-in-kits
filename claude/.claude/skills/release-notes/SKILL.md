# Release Notes and Cutover

Find the last relevant release tag and merged changes since it, using available
repository history and PR metadata. Group verified user-visible changes into
Added, Fixed and Breaking Changes, with references and migration notes. Prepare
a deployment checklist covering prerequisites, verification, monitoring and
rollback. If tags, history or deployment details are missing, state the gap and
ask for the release range or owner guidance; never invent release contents.
